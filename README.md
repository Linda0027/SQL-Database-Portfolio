## 📁 Project Architecture & Components
* **[`01_schema_creation.sql`](./01_schema_creation.sql):** Data Definition Language (DDL) modeling an enterprise infrastructure ticketing system. Implements primary keys, strict check parameters (`CHECK`), multi-table foreign keys, and mock transactional tables.
* **[`02_analytical_queries.sql`](./02_analytical_queries.sql):** Advanced Data Manipulation Language (DML) querying data using three-way inner joins, aggregated conditional counts (`CASE WHEN`), and conditional logic using correlated subqueries.
* **[`03_fitnesscentre_schema.sql`](./03_fitnesscentre_schema.sql):** Official **IIE Rosebank College (DBAS6211)** practical assessment script mapping parent-child tables (`Customer` & `Orders`), validating relational integrity, row updates, and database row deletions.
