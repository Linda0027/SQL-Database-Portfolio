# 📊 Advanced SQL & Relational Database Portfolio

Welcome to my database development repository! This workspace showcases practical assignments, normalized relational schemas, and complex transactional data operations completed during my **Bachelor of Information Technology in Business Systems** curriculum at IIE Rosebank College (where I achieved an **82% Pass with Distinction in Databases**).

## 📁 Project Architecture & Components
* **[`01_schema_creation.sql`](./01_schema_creation.sql):** Data Definition Language (DDL) modeling an enterprise infrastructure ticketing system. Implements primary keys, strict check parameters (`CHECK`), multi-table foreign keys, and mock transactional tables.
* **[`02_analytical_queries.sql`](./02_analytical_queries.sql):** Advanced Data Manipulation Language (DML) querying data using three-way inner joins, aggregated conditional counts (`CASE WHEN`), and conditional logic using correlated subqueries.

## 🚀 Key Technical Core Competencies
* **Relational Schema Integrity:** Building secure structural relationships with cascading database execution guidelines.
* **Database Normalization:** Standardizing messy raw source arrays up to Third Normal Form (3NF) to eliminate structural redundancies.
* **Data Retrieval Operations:** Developing optimized structural pipelines using query filters and multi-stage subquery metrics.
